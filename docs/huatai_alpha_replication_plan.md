### 1.3 复现边界与原文内部歧义

本项目是**原公式的近期市场、不同股票池再检验**，不能称为原报告收益曲线的完整复现。中证500是原报告部分组合的比较基准，不代表其研究股票池就是中证500。

原报告第11页写下一交易日收盘价换仓，第18页有效因子分层测试写下一交易日 VWAP，并有调仓时点文字不够一致之处。成交价的统一口径**待确认**；未来实现必须明确选用一种执行规则并披露差异。原报告对下一日停牌的剔除也不能自动当作时点 t 已知的信息；本项目需区分事后成交失败与事前资格。

第11页关于标准化后“近似正态”的描述不作为本项目统计假设：减均值、除标准差本身不保证正态。报告每日重叠收益对应的 ICIR也不能视为独立观测的显著性统计量。

## 2. Factor Definitions

### 2.1 华泰原公式与作者原公式，分别列示

以下华泰公式逐项来自[第6页图表2](https://crm.htsc.com.cn/doc/2019/10750101/dae9cd9e-c2cd-4f05-bb6c-e5ac8d216d3d.pdf#page=6)，并以[第32页图表50](https://crm.htsc.com.cn/doc/2019/10750101/dae9cd9e-c2cd-4f05-bb6c-e5ac8d216d3d.pdf#page=32)交叉核对：

```text
Alpha3  = (-1 * correlation(rank(OPEN), rank(VOLUME), 10))
Alpha13 = (-1 * rank(covariance(rank(CLOSE), rank(VOLUME), 5)))
Alpha44 = (-1 * correlation(HIGH, rank(VOLUME), 5))
```

作者论文 Appendix A 的对应公式为：

```text
Alpha#3:  (-1 * correlation(rank(open), rank(volume), 10))
Alpha#13: (-1 * rank(covariance(rank(close), rank(volume), 5)))
Alpha#44: (-1 * correlation(high, rank(volume), 5))
```

出处：[作者预印本第8页 Alpha#3、第9页 Alpha#13、第11页 Alpha#44](https://arxiv.org/pdf/1601.00991v3#page=8)。三个公式除大小写、编号写法外一致；这不意味着输入预处理、rank数值约定和研究股票池已经证实一致。

### 2.2 算子、时间方向和数值契约

下表语义来自[华泰第5页图表1](https://crm.htsc.com.cn/doc/2019/10750101/dae9cd9e-c2cd-4f05-bb6c-e5ac8d216d3d.pdf#page=5)及[作者预印本第15—16页](https://arxiv.org/pdf/1601.00991v3#page=15)。右栏是为获得可重复实现而另行约定的细节。

| 算子 | 文献含义 | 本研究拟定实现契约 |
| --- | --- | --- |
| `rank(X)` | 同一日期、多只股票的截面排序；华泰定义为分位数 | 升序、并列取平均秩、除以有效证券数N，缺失保留。N<2无有效截面。排名集合见2.5；不能用个股时间序列rank替代 |
| `ts_rank(X,d)` | 同一股票过去d天中当前值的排序/分位数 | 包含当日，按完整d个市场交易日；并列平均秩/d。三个目标公式均不需要此算子 |
| `correlation(X,Y,d)` | 同一股票过去d天两序列的相关系数 | 采用 Pearson 时间序列相关；不是对原始量价直接计算 Spearman。窗口包含t及此前d−1个市场交易日，必须d对完整观测 |
| `covariance(X,Y,d)` | 同一股票过去d天两序列的协方差 | 样本协方差，`ddof=1`，必须d对完整观测。不是截面协方差 |
| `delay(X,d)` | d天前的X | 升序市场日历上的t−d；正d向过去。不是读取t+d |
| `delta(X,d)` | `X-delay(X,d)` | `X_t-X_{t-d}`；三个公式均未调用 |

原文没有明确说明rank并列值、分位数端点、协方差分母、缺失时最少观测数；这些原始实现细节均为**待确认**。本研究采用的完整窗口、平均秩、`ddof=1`属于自主约定，须写入元数据和测试。样本完整且d一致时，`ddof=0/1`只对协方差作统一正比例缩放，不改变 Alpha13 最外层rank；若不同股票使用不同有效样本数，则不成立。

记 `R_u(X)` 为日期u在指定集合内的截面分位秩，`W_d(t)={t-d+1,...,t}` 为市场交易日窗口。给定股票i：

\[
A3_{i,t}=-\operatorname{Corr}_{u\in W_{10}(t)}
\left(R_u(O)_{i},R_u(V)_{i}\right).
\]

\[
C_{i,t}=\frac{1}{4}\sum_{u\in W_5(t)}
\left(R_u(Close)_i-\overline{R(Close)}_i\right)
\left(R_u(V)_i-\overline{R(V)}_i\right),\qquad
A13_{i,t}=-R_t(C)_i.
\]

\[
A44_{i,t}=-\operatorname{Corr}_{u\in W_5(t)}
\left(H_{i,u},R_u(V)_i\right).
\]

上式 Alpha13 的中间符号C代表协方差，不代表收盘价；横线表示窗口内时间均值。若使用2.5推荐的当期固定排名集合，记号 `R_u` 应严格写作 `R_u^{(t)}`，以保留排名集合版本。

### 2.3 三因子的计算顺序、数据和经济含义

| 因子 | 顺序与原始数据 | 最小历史要求 | 解释与方向 |
| --- | --- | --- | --- |
| Alpha3 | 每个历史日分别对OPEN与VOLUME做截面rank → 每只股票取最近10日两条秩序列的时间相关 → 乘−1 | 包含t在内10个连续市场交易日，故需要t前9日；每日还需要排名集合中其他股票的开盘价、成交量 | 开盘价相对位置与成交量相对位置越背离，数值越高。公式表达的是负相关得分；“高值预测较高收益”是待检验的实证假设 |
| Alpha13 | 每日分别对CLOSE、VOLUME做截面rank → 每股最近5日时间协方差 → 在t对各股协方差再做一次截面rank → 乘−1 | 包含t在内5个市场日，t前4日；需要完整截面及t时其他股票的有效协方差 | 选择价格秩与量秩协动较弱/反向的股票。外层是先rank再乘−1，不能替换为`rank(-cov)`并声称数值完全相同；负数中接近0的值较高 |
| Alpha44 | 每日只对VOLUME做截面rank → 每股最近5日HIGH与量秩做时间相关 → 乘−1 | 包含t在内5个市场日，t前4日；需要HIGH与完整成交量截面 | 最高价轨迹与市场内成交量相对位置背离。**HIGH不做rank**，也不能误写为Alpha16 |

三者都不需要 VWAP、amount、行业或市值才能计算原始得分；共同对照 MOM20 需要21个价格端点（t与t−20之间的市场日历位置必须准确）。三个 Alpha 以当日完整成交量为输入，统一在t日收盘后可知；Alpha3使用OPEN也不意味着它可在当日开盘执行。

Alpha3/44有效值应在[−1,1]。按本研究rank分位数定义，Alpha13在[−1,0)内，具体上界取决于有效截面大小和并列值。三者都保留原公式负号，不能看到近期IC为负后翻转方向。华泰样本的正向关系已列于1.2，近期可能无效或反向，均应如实报告。

“背离”是统计描述：这里的价格秩不是收益率、量秩不是换手率，结果可能包含价位、股份规模和行业暴露；不应进一步推断为资金流向或因果机制。

### 2.4 价格复权和成交量处理

**原文确认范围：**华泰第5页明确RETURNS由后复权收盘价得到，第17页明确IC收益标签用复权收盘价比值。但图表1没有明确OPEN/CLOSE/HIGH/LOW究竟用未复权、前复权还是后复权，也未交代VOLUME是否作拆股调整。作者预印本第16页同样只给标准日频价格/量定义。因此不能宣称“原研报要求前复权”或“原研报使用原始成交量”。这些细节均**待确认**。

**本研究建议预先冻结的价格方案：**原公式主规格使用现有未复权OHLC和未调整vol，标注为本研究输入约定；收益标签与MOM20用复权收盘价。另设一个事前声明的稳健性规格，将全部价格输入改为固定历史锚点的复权价，并同时报告，不能从两者中挑效果较好的充当主结果。若后续获得华泰输入证据，应在看结果前更新主规格。

记原价为P，累计复权因子为a，可构造：

\[
P^{adj}_{i,u}=P_{i,u}\,a_{i,u}/b_i,
\qquad
y_{i,t,h}=\frac{Close_{i,t+h}a_{i,t+h}}
{Close_{i,t}a_{i,t}}-1.
\]

其中 `b_i` 必须固定、登记，并在输出时点之前已知；建议以该股票文件中首个历史观测日的a作为固定锚点，且不因追加新数据而变。将来需核实其与供应商后复权定义的一致性。不可把未来最新a作为自动变化的全历史前复权锚点用于横截面价格rank。以上是数据版本内的时序因果约束，不能消除供应商事后修订，仍需披露非历史版本数据。

- 同一股票价格比值中的固定b会抵消，所以MOM20、收益标签通常不受固定锚点影响；跨证券的价格rank却会受股票各自b影响，**不能套用该抵消结论解释Alpha3/13**。
- 对Alpha44，给某股整个5日HIGH序列乘同一个正数不改变相关系数；窗口内随时间变化的复权因子仍可能改变结果。
- 未复权价格可能将除权造成的台阶混入信号；复权价格的截面价位又依赖归一化基准。必须保留两种口径及公司行动标记，不能认为一种选择自动无偏。
- `vol`由手变成股统一乘100，不改变三个公式中的截面rank。没有必要为了三个因子改写磁盘成交量。
- 不应直接用累计`adj_factor`反向缩放成交量：它可能同时反映现金分红、送转、配股，未必是纯股份数量调整因子。真要构造拆股调整成交量，须补事件证据并作为单独规格；目前不具备认证条件。

### 2.5 完整价格历史与排名集合：必须分开定义

所有股票的历史行情先保留、排序、对齐；不得先将行情与membership做inner join，再计算滚动因子或标签。退出指数的股票也保留标签终点行情。**但“有1263只历史股票的完整价格”不等于“任何历史截面都能对1263只股票排名”。** 后者的集合由未来入选经历筛出来，可能让未来成分信息进入历史rank。

本地只有历史中证500并集，缺少全A同时点排名母体。华泰全A测试中rank母体的精确资格细节也未完全说明。三个公式中的`rank`都必须登记`rank_universe_policy`。建议本次研究采用如下可执行的主规格：

1. 在每个信号日t，确定近似PIT的当期集合`M_t`，完全不看未来收益和未来成员记录。
2. 将`M_t`作为本信号窗口的固定排名参照集合。在窗口内每个历史日u，利用完整行情计算`R_u^(t)`；股票即使u时还没有入选，只要u有真实行情，也可在此参照集合中排名。缺失行情不填补。
3. 再按原公式完成时间运算；Alpha13外层rank使用t时`M_t`内协方差有效的股票。得到得分后，才按当日资格和研究日期构建最终研究样本。

这是**当期成员固定参照集合的自主设计**，在t只使用当时集合与截至t的历史价格，既保留入选前历史，也避免用未来全期成分并集作排名母体。它并不等于在每个历史u使用`M_u`的标准日期截面缓存；不能把两种结果混称为同一实现，更不能宣称已还原华泰全A排名口径。实现时可逐信号日的小窗口处理，不需要先删除非成员价格。

预先登记的敏感性规格为“各历史日使用当时`M_u`排名”。它会使首次入选者即便有完整历史价格，也可能缺少4/9天的历史**排名**；这是该母体定义的覆盖损失，须与行情缺失分开报告，不能静默丢弃或用未来成员补齐。若希望同时实现全A历史日排名及入选即有完整排名窗口，必须获得覆盖更广且可时点识别的数据，当前资料不足。

该选择是开始编写Alpha前必须写进接口和测试的研究约定。本报告推荐固定当期参照集作为现有数据条件下的主规格，而不将这一未证实的细节描述为“华泰原定义”。

### 2.6 缺失、零方差、停牌与无交易

采用统一市场交易日网格，先明确记录类型，再计算因子：

| 情形 | 拟定规则 |
| --- | --- |
| 数据起点前、未上市或新股历史不足 | 完整窗口不足则因子NaN；真实上市状态未取得时不能仅凭首条行情认定未上市 |
| 停牌/日历内无记录/原因未知 | 在网格中留NaN及原因标记；无记录不能一律叫停牌，不用下一条有效行情挤进窗口 |
| 有行情但vol=0 | 标记无有效交易，不把它当正常量价观测；不将停牌缺行补成vol=0。本地当前文件未检出非正vol |
| 非有限、非正价格或无效复权因子 | 输入失败，保留问题清单；不得用0填补 |
| Alpha3/44任一时间序列零方差 | 相关系数未定义，输出NaN；不把0或±Inf当成正常因子值 |
| Alpha13时间序列常量 | 在完整5对观测下协方差为0是合法值，允许进入外层rank；它不因相关系数未定义而自动变成NaN |
| Alpha13所有协方差相同 | 可得到相同秩，但横截面无区分力；该日RankIC未定义，不应记为0 |
| 窗口中有任一必要缺失 | 采用完整d日要求，不逐股删掉NaN后压缩到d条记录，也不以少量有效观测替代固定窗口 |

价格、量的排名有效集合采用该日必要输入均有效的股票，所有因子应记录其N、窗口完整性及原因。排名母体不得依赖该股票在后续日期是否有收益标签。

### 2.7 原论文与华泰定义差异

### 3.3 动态股票池源码与文件核对

`src/data/download.py:21–47`按月请求`index_weight`和2016—2025年SSE开市日。`src/data/universe_process.py:21–30`采用：

```text
merge_asof(trade_date, snapshot_date, direction='backward')
→ 将该日期最近的不晚于它的快照展开为当日membership
```

当前算法没有把下一张月末快照向过去回填；它会在下一张快照之前继续持有上一张快照，因而可能滞后于真实调整生效日，也可能遗漏月中临时变动。快照的权重不等于快照文件的可获得时间。

本次只读核验结果：

| 项目 | 结果 |
| --- | --- |
| 原始权重快照 | 61,000行；122个日期；2015-12-31—2026-01-30；历史1264个标识 |
| membership | 1,215,000行；2430日；2016-01-04—2025-12-31；1263个标识 |
| 每日唯一成员数、重复主键 | 每日500；重复0 |
| `source_snapshot_date > trade_date` | 0行 |
| 在快照当日使用该快照 | 60,000行；没有盘前/盘后可知时间证据 |
| 按现有raw快照重算日期映射 | 与成品来源日期差异0；成员和weight匹配差异0 |

这些检查证明文件符合现有“向后沿用快照”算法，**不能证明严格PIT**。所有membership均缺少公告时间/真实生效区间，统一标为近似PIT。对快照同日使用可做延后一市场日敏感性检查，但延后一天不能修复所有公告及月中变动问题。

当前下载源码仅请求2016—2025的月份，但raw文件还包含2015-12-31和2026-01-30快照，生成批次/补边界步骤**待确认**。不能声称当前脚本从零运行必然还原现有文件，尤其最初快照决定2016年起始覆盖。

`src/data/download_market.py:14–18,25–52`使用membership历史标识并集，为每只股票请求2015-09-01—2026-02-28全区间行情，而不是只保留成员期。该做法有利于回看和退出后标签，并集在这里是**下载范围**，不是每日研究资格。实际文件中，早于股票首次membership的行情有674,218行（1257个标识），晚于末次membership的行情有781,083行；只证明数据被保留，不保证每次入选/退出附近都有完整窗口。

当前`download_market.py:46–57`左连接adj_factor、`validate='one_to_one'`，存在NaN时打印提示后仍写文件，**没有dropna**。旧质量报告有“此处直接dropna”的描述，与当前源码不一致；本文不沿用那项判断。没有多年度原始响应、历史运行日志和生成版本，是否曾经发生合并删行仍待确认。

多年行情的Arrow schema中ticker、trade_date为`large_string`（pandas字符串）；OHLC、vol、amount、adj_factor均为double/float64。日期是八位字符串，研究层应严格按`%Y%m%d`转换为无日内时区的交易日期，按`(ticker, trade_date)`升序排序，并验证唯一主键。

本次对行情的必要只读检查：全列空值0，数值非有限0，OHLC/vol/amount/adj_factor非正0，重复主键0，OHLC高低价关系违规0。1263只股票全部是日期倒序，升序股票数为0。字段数值合法不代表证券日齐全、事件处理正确或历史版本PIT。

[TuShare daily官方文档](https://tushare.pro/document/2?doc_id=27)明确日线OHLC未复权、vol单位为手、amount为千元，停牌不提供行情；[adj_factor官方文档](https://tushare.pro/document/2?doc_id=28)说明这是供应商生产的复权因子。当前下载脚本直接保存这些单位，没有成交量换算。本次用`amount*10/vol`做量纲核验，允许0.01元价格舍入容差后落在[low,high]之外的记录为0；该核验支持单位一致，不能证明每笔交易真实。

对membership左连接行情：全期1,215,000行中有1,193,783行匹配，缺21,217行。2023—2025年共727个交易日、363,500个成员证券日，其中278行无行情（约0.0765%）。缺失原因仍须分类，不能将其全部解释为停牌或下载失败。

仅比较日期、不计算收益或因子时，按股票后续有效记录位移与市场日历终点确有差异。在2023—2025信号日、当日属于membership、且本地2016—2025网格内存在第h条后续观测的记录中：5条记录位移错位194次，20条记录位移错位727次。这不包含无后续观测、跨2026或其他截断情形，不是最终标签缺失总数。

具体例子：`000403.SZ`的2025-05-29信号，第5条后续观测在2025-06-10，但第5个市场交易日在2025-06-06；2025-05-08的第20条后续观测同样在2025-06-10，而第20个市场交易日是2025-06-06。**不能将`groupby().shift(-5/-20)`无条件命名为5/20个市场交易日收益。**

| 主指标 | Mean RankIC、非年化ICIR、IC>0比例、coverage | 前三者与华泰评价框架一致；coverage为本项目必要补充 |

这些设置总体合理，但不具备“原报告的中证500完整复现”资格。建议以20日期限为经济解释重点，5日为预先指定的比较期限，全部结果保留；不根据显著性或收益决定展示哪个期限。

名义样本期与实际可估计终点必须同时注明。当前方案不使用2026日历未经核实的日期，最后5/20个信号日因设计性终点不足而不进入对应IC分析，但仍保留资格记录。若以后补齐已授权的2026日历，可预先约定将已有2026行情仅用于标签，使2025全部信号可评估；它不需要2026年membership，因为预测对象在t已经确定。此变更须在看结果前登记，不自动发生。

### 5.2 数据流和资格、因子、标签的分离

1. 建立只读原始数据清单，固定hash、版本、列定义；不覆盖原Parquet。交易日期解析后升序，主键冲突立即报错。
2. 以独立市场开市日历对齐每股时间轴，保留未知缺口和事件标记；明确股票代码实体映射的局限。完整历史层包含入选前、退出后行情。
3. 构建每个t的**事前资格表**：研究日期、当期近似PIT成员、当日必要输入质量、可用历史。没有标签列也应能得到同样的资格和分组。
4. 按冻结的rank母体、价格规格，在完整历史行情上生成得分及窗口完整性标记，然后应用当期研究资格。membership用于定义rank参照集，不得用于物理删除价格历史；不能先切出2023年后再做rolling。
5. 在完整价格层按**确切市场日期**连接t+h端点，生成标签；不要求股票在t+h仍是成员。标签属于评估层，不可成为资格、rank或分组输入。
6. 保存`eligible_t`、`factor_available`、`label_available_h`及原因，三者分列。只在数学上需要配对的IC/均值中使用可观测标签，不提前用未来标签删行，不全表dropna。
7. 用同一事前规则评估三Alpha和MOM20；保留每日原始IC、N、未配对数、缺失原因，再汇总。因子共同可用样本用于可比性敏感性，但不能取代各因子的原始覆盖结果。

“先算完整历史再筛研究样本”不要求对缺少输入的股票制造得分。它要求历史窗口不被资格连接意外截断，并使每次排除都有当时数据理由。

### 5.3 未来收益的明确含义和缺失政策

主研究标签为：t收盘后已知因子，与t收盘至第h个市场交易日收盘之间的复权价格收益的相关性，公式见2.4。使用日历确定终点日期，不用该股票第h条有效记录。

这是**统计预测标签**，不意味着t收盘后还能按t收盘价成交。后续交易回测应另定义t+1的成交价、退出时间和费用；不能把这种标签收益累计后称为可交易策略净值。

端点无行情时保留标签缺失；不查找下一个有价日、不将停牌填为零收益、不删除该股的事前资格。已经存在真实t+h端点且中间短暂停牌时，端点收益可计算，同时记录中间缺口；不能因此声称全程可按计划交易。退市/吸收合并可能涉及最后可交易价和现金结算，缺少事件表时不能把无终点股票视为收益0或自动−100%。

IC必然只能在有配对标签的观测上计算，因此仍可能存在非随机缺失偏差。每日必须报告“事前候选数→因子可用数→标签可观测数”，分组也要报告已分组但标签缺失的数量；对长期停牌、退市候选单独分析。若这些缺失无法合理归因，结论必须限定为“可观测收益子样本”，不能宣布消除了存活偏差。后续可用合理收益边界作敏感性分析，边界规则需有经济和事件依据，不能为显著而设。

### 5.4 指标、五分组和统计推断

每日计算：

\[
IC_{t,h}=\operatorname{Spearman}_{i}(A_{i,t},y_{i,t,h}),\qquad
ICIR_h=\frac{\overline{IC_h}}{s(IC_h)},\qquad
PositiveRatio_h=\frac{\#\{t:IC_{t,h}>0\}}{\#\{t:IC_{t,h}\text{有限}\}}.
\]

ICIR采用样本标准差`ddof=1`，主表不年化。标准差为0、截面变量常量或样本不足时输出“不可估计”，不输出无穷大或补0。正值比例分母不包括未定义日；零IC不是正值。各期限标签长度和自相关不同，不按ICIR大小直接宣称某调仓频率更好。

本研究拟定每日最少100个有效配对才计算IC（约500成员的20%，纯质量阈值，不以收益调参），同时给原始N和缺失日；任何单日排除必须列示。全期、2023/2024/2025分别报告均值、标准差、ICIR、正值比例、有效天数和覆盖率；年度拆分是稳定性描述，不把表现最好一年当主结果。绘制每日IC、累积IC和预先固定60市场日滚动均值，滚动图只用于描述。

五分组先按当日因子值分配，之后再连接标签。建议采用平均秩分位区间分桶（0—20%等），不对相同值用股票代码强行制造高低顺序；并列导致组数不足/空组时，该日标记不可用于完整五组单调性检验，保留并列及组容量统计，不静默换成三组。完整五组并不保证人数严格相等，偏离需报告。

报告五个组的h日平均标签收益、Q5−Q1、五组均值与组号的秩相关、四对相邻组收益差。按日先平均、再跨日平均，避免把股票多的日期赋予更高权重；组内缺失标签的原定成员仍计入coverage分母。Q5−Q1是可观测标签的排序诊断，**不能将每日重叠h日收益直接复利或年化为资金曲线**。

统计显著性方案在运行前冻结：

- 每日标签存在h日重叠，IC序列还可能有超出h−1的相关。均值采用常数项时间序列回归的Newey–West/HAC标准误和95%置信区间，主规格滞后20市场日，固定60日作敏感性；不把`mean/std*sqrt(T)`当独立样本t检验。[方法来源：Newey与West原始工作论文](https://www.nber.org/papers/t0055)。
- 预留市场日期位置，不能删掉未定义日后把相隔数天的IC当相邻日。实现应使用日期感知的协方差估计或明确连续子样本，并登记方法；对有效日过少/缺失过多的情形停止显著性解释。考虑用固定60交易日移动块bootstrap给均值和正值比例的辅助区间，时间块内保留横截面依赖。
- 主检验族定义为4因子（含MOM20）×2期限，共8个双侧零均值检验，统一给出原始p值和Holm校正p值，家族错误率0.05；正向预期只用于解释，不事后改成单侧检验。[方法来源：Holm原论文](https://www.ime.usp.br/~abe/lista/pdf4R8xPVzCnX.pdf)。
- 年度、价格版本、排名母体、未来中性化、增量信息均属预设辅助分析。若据此提出额外“显著发现”，应登记扩大的检验家族并重新控制多重检验；不能只在主表8项里校正，却从所有试验里挑最好结果。
- 除显著性外同时报告效应大小、区间和覆盖；未拒绝零假设不等于证明完全无效。三年日频数据也不等于有727个独立的20日预测。

### 5.5 行业市值中性化及MOM20增量信息

补齐历史可知行业和市值后，在同日截面按“去极值→中性化→标准化”进行。去极值采用华泰中位数±5MAD版本；MAD=0须显式处理，不能把截面错误压成常量。中性化以因子为因变量、对数总市值与行业哑变量为自变量，取残差；有截距时需去掉一个行业，或采用无截距全行业哑变量，避免设计矩阵秩亏。标准差为0输出不可估计，回归样本和缺少行业的股票逐日披露。该步骤是得分预处理，不改写三个原始公式。[原处理顺序：华泰第11页](https://crm.htsc.com.cn/doc/2019/10750101/dae9cd9e-c2cd-4f05-bb6c-e5ac8d216d3d.pdf#page=11)。

中性化前后在相同可用证券日上比较IC及覆盖，同时保留未中性化全可用样本结果，避免“改善”仅来自删掉缺行业的股票。当前没有所需数据，不构造伪行业、市值代理，不自行下载。

增量信息先比较三Alpha与MOM20的当日截面秩相关；再分别将每个Alpha的当日秩得分对MOM20秩得分做截面回归，用残差计算未来RankIC。也可做每日`future_return ~ standardized_MOM20 + standardized_Alpha`回归，检验Alpha系数时间均值，时间推断仍用HAC。行业/市值具备时再加入相同控制。残差化只能说明相对于所选函数形式的额外排序信息，不能直接声称非线性独立信息、因果效应或样本外组合增益。若拟合组合权重，必须按时间训练/验证并留足至少20市场日的标签隔离，禁止用测试期收益拟合权重。

### 5.6 交易费用和超额收益：后续独立阶段

原始RankIC和五组标签不是费用回测。后续先固定可实现规则：t收盘信号，t+1成交，h=20作为预设主要持有期，h=5为比较；若采用t+1开盘至t+1+h开盘，应明确该期限与主研究收盘标签不同。全日VWAP可由`amount*10/vol`构造诊断值，但不能仅凭日线假定任何订单都能成交于该VWAP。

以Q5多头和同池等权参考组合做初步可实现性比较；官方中证500超额收益须有实际基准收益数据。Q5−Q1仅作研究性多空指标，A股融券可得性、借券成本及限制未建模时，不称为可实施多空策略。真实指数收益与同池等权收益分别命名。

先以单边15bp作为与华泰接近的**研究费用假设**，10/20bp做事前敏感性，不声称等于2023—2025真实税费。若用费率c乘交易金额比例，则成本为`c * sum(abs(target_weight - pretrade_drifted_weight))`，买卖两边均计费；若定义单边换手为绝对权重变化和的一半，须相应转换，避免少计/重复计费。实际税费、滑点、冲击和卖出税率的历史规则另核实，不在本次假设中伪装为精确还原。

必须明确重叠子组合的资金分配、不同调仓起点、交易未成交、涨跌停、停牌时持仓估值和延迟卖出、退市结算、成分退出后的处置规则，以及A股T+1约束。不能根据未来持有期是否完整决定买入名单。完成持仓/现金/费用核对后，才计算年化收益、相对基准超额收益、波动、Sharpe、信息比率、最大回撤、换手和容量。现有项目不具备这些模块与完整状态数据，本次不实施。

### 8.3 算子与因子阶段

- 用至少10个日期、多只股票的非平凡人工面板，逐步手算每日rank、单股窗口相关/协方差、Alpha13外层rank；向量化结果与简单标量参考逐元素一致，浮点误差建议`atol=1e-10`。

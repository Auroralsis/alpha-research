# 中证500：量价因子方法复现

本实验在 2023-01-03—2025-12-31 的动态中证500上，对三个量价因子应用[原报告](https://crm.htsc.com.cn/doc/2019/10750101/dae9cd9e-c2cd-4f05-bb6c-e5ac8d216d3d.pdf#page=10)的回归与分层方法。原报告为2010—2019年全A股；本实验不是对其数字的重现。

## 口径与数据限制

- 无完整历史ST/PT和停牌事件表。回归和IC以次日有正常行情近似排除停牌（在有下一交易日的范围内，277条成员记录没有通过该代理）；只作为事后统计样本掩码。因子计算、预处理及组合目标不读取次日数据。报告不把缺行情认定为确切停牌。
- 单日IC、WLS均要求至少100对；各期限有效天内，最少 IC 配对和 WLS 配对分别为 490 和 490。行情用原项目的动态成员、原始价格和信号日成员排名参照。成员和行业只有近似的历史可得性；本样本曾用于研究，不是完全未接触的样本外区间。
- 收盘涨停不买、跌停不卖，缺有效收盘价或官方限价不成交。卖不出的清仓单以后重试，未成交的新买单不补买；缺有效收盘用上一个可用收盘估值。不重建集合竞价可成交量、冲击、整手、公司行动现金与退市清算。原文未完整披露这些成交细节，属本实验约定。
- 原文也考查其他中性化组合及参数；本轮只比较不中性与行业/市值中性，不复制依赖额外风格数据的设定，也不调参去追原报告收益。指数是价格指数。

主20日口径共 6 个因子/预处理回归及 IC 组合、60 条最高分层轨道。

复现：`python -B -m src.scripts.run_factor_study`。参数在 [design.json](../results/factor_study/design.json)，输入版本在 [manifest.json](../results/factor_study/manifest.json)。
